# Diario Cani

App web (PWA) per seguire la salute di **Kafka** (epilessia) e **Zoe**: crisi, terapie e cambi di dose, analisi, vaccini, problemi e visite, con statistiche e report PDF/CSV per il veterinario.

## Messa in funzione
1. Crea un progetto su [Supabase](https://supabase.com), apri **SQL Editor**, incolla `schema.sql` e premi **Run**.
2. In `config.js` inserisci URL del progetto e chiave **anon** (Project Settings → API).
3. GitHub: Settings → Pages → Source: **GitHub Actions**.
4. Apri il link in Safari su iPhone → Condividi → **Aggiungi a schermata Home**.
